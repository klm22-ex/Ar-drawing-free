# AR Drawing Free

Application web gratuite pour apprendre à dessiner avec une image modèle, la caméra du téléphone et un espace de dessin libre.

## Fonctionnalités de cette première version
- Caméra arrière (si autorisée par le navigateur)
- Superposition d'une image modèle avec réglage d'opacité et de taille
- Espace de dessin libre avec couleur, épaisseur, gomme et annulation
- Export du dessin en PNG
- Conseils pour débuter

## Publier l'application avec GitHub Pages
1. Ouvre l'onglet **Settings** du dépôt.
2. Dans le menu, choisis **Pages**.
3. Sous **Build and deployment**, choisis **Deploy from a branch**.
4. Sélectionne la branche **main**, puis le dossier **/(root)**.
5. Appuie sur **Save**.
6. Attends quelques minutes : GitHub affichera l'adresse publique du site dans cette même page.

La caméra nécessite HTTPS et l'autorisation d'accès à la caméra dans le navigateur.

Projet indépendant, créé pour l'apprentissage du dessin.
